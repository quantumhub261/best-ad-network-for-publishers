# best-ad-network-for-publishers.com

Static site. Build: `node build.js` (output: `dist/`). Cloudflare Pages: build command `node build.js`, output directory `dist`.

Content lives in `home.js`, `mobile.js`, `admob.js`, `about.js`, `methodology.js`, `privacy.js`; outbound links in `links.js`; styles in `style.css`.
